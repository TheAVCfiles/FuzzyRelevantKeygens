# AUTOGRAPHY — Build Spec

Target: single Node/Express + React app deployed on Replit. SQLite or Replit DB for state. No auth system needed for the demo — role is switched by a query param (`?as=star` / `?as=public`).

---

## 1. Data model

### Call — the credential

The whole thesis in one object. Person-held, issuer-attested, scoped, expiring.

```json
{
  "call_id": "CALL-SF06-LV-0001",
  "subject": { "id": "lola-vantz", "display": "Lola Vantz" },
  "issuer": { "id": "saltflats-prod", "display": "The Salt Flats (Production)" },
  "attestation": "issuer",
  "engagement": { "show": "The Salt Flats", "episode": 6, "capacity": "principal cast" },
  "window": { "valid_from": "2026-09-04T23:00:00Z", "valid_until": "2026-09-05T07:00:00Z" },
  "scopes": ["drop:issue", "room:open", "offers:receive", "likeness:still"],
  "exclusions": ["claim:third-party-conduct", "brand:alcohol", "endorse:political"],
  "reach": { "territory": "worldwide", "platform": "any" },
  "sig": { "issuer_sig": "...", "subject_countersig": "..." }
}
```

Rules the code must enforce:
- `attestation` ∈ `self | document | rep | issuer | union`. Never render as "verified" — render the actual level.
- `exclusions` always beat `scopes`. A scope can never unlock an exclusion.
- A Call with only `issuer_sig` and no `subject_countersig` is **inert**. It authorizes nothing.
- `valid_until` is the ON AIR light. Nothing else turns it off.

### SignalEvent — one item in the flood

```json
{
  "id": "sig_0001",
  "text": "...",
  "author": { "handle": "...", "account_age_days": 6, "followers": 12 },
  "posted_at": "2026-09-04T23:41:12Z",
  "platform": "synthetic",
  "engagement": { "likes": 3, "reposts": 41 }
}
```

### Cluster — Gemini's grouping, with visible reasoning

```json
{
  "id": "cl_a",
  "label": "Repayment accusation, near-identical phrasing",
  "class": "coordinated_likely",
  "member_ids": ["sig_0004", "sig_0011", "..."],
  "coordination_signals": {
    "duplicate_phrasing": 0.91,
    "account_age_clustering": 0.88,
    "burst_window_seconds": 340,
    "cadence_irregularity": 0.76
  },
  "confidence": "high",
  "note": "Likelihood, not finding. Signals shown below."
}
```

`class` ∈ `coordinated_likely | authentic_concern | press | first_party | insufficient_evidence`

**Never** compute a percentage of "public opinion." Compute *share of observed volume* and label it that.

### PullRequest — the staged response set

```json
{
  "id": "pr_001",
  "opened_at": "...",
  "finding": {
    "observed_volume": 1284,
    "coordinated_share": 0.71,
    "authentic_concern": "Viewers are confused about a three-week gap in the repayment timeline, not the accusation itself.",
    "commercial_exposure": ["Active skincare partnership — no defection observed, press pickup risk rising"]
  },
  "moves": [ { "id": "mv_hold", "label": "Stay dark", "...": "..." } ],
  "state": "open",
  "merged_move_id": null
}
```

Exactly three moves, always including **Stay dark** as a first-class option with its own projected outcome. Silence must be a real choice, not a null state.

### Drop — the issued artifact

```json
{
  "drop_id": "DROP-SF06-0001",
  "call_id": "CALL-SF06-LV-0001",
  "edition": { "number": 1, "of": 2500 },
  "claims": [
    { "text": "...", "source_class": "verified_document", "source_ref": "ctx_receipt_0412" }
  ],
  "hash": "sha256:...",
  "seal": { "issued_at": "...", "signed_by": "lola-vantz", "scope_ref": "drop:issue" }
}
```

`source_class` ∈ `verified_document | first_party_statement | third_party_reporting | audience_interpretation | model_inference` — rendered visibly on every claim, in the artifact itself. This is the credibility mechanism and it is not optional.

### Receipt — append-only log

Every issue, exchange, refusal, and expiry. `{ ts, actor, action, call_id, result, rule_fired }`. Append-only. This is what the final screen renders.

## 2. The Velvet Rope — deterministic policy engine

Plain functions. No model call anywhere in this path. Runs on every proposed drop, in order, first failure wins.

| Rule | Check | Failure state |
|---|---|---|
| R1 `window` | `now` within `valid_from..valid_until` | `DARK` |
| R2 `countersig` | `subject_countersig` present and valid | `INERT` |
| R3 `scope` | requested action ∈ `scopes` | `OUT_OF_SCOPE` |
| R4 `exclusion` | no claim matches `exclusions` | `EXCLUDED` |
| R5 `evidence` | every claim about a third party has `source_ref` resolving into context repo | `HUMAN_HOLD` |
| R6 `reach` | target platform/territory within `reach` | `OUT_OF_REACH` |

Each failure returns the rule id, the human-readable reason, and the receipt entry. **The refusal is a feature — render it beautifully.**

R4 and R5 are what stop *"Say Marisol stole it."* R5 fires because the context repo contains no substantiating document. The system does not decide whether it's true. It reports that the evidence required to say it does not exist.

## 3. Gemini + Agent Builder touchpoints

Four calls. All read-and-draft. None decide.

| # | Input | Output | Model role |
|---|---|---|---|
| G1 | Episode still + transcript excerpt (multimodal) | Structured scene summary: who, what, what a viewer would infer | Read |
| G2 | Flood (all SignalEvents) | Clusters with class + coordination signals | Classify |
| G3 | Clusters + context repo | The authentic concern, distinct from loudest claim | Reconcile |
| G4 | G3 output + context repo + Call scopes | Three drafted moves with projected outcomes | Draft |

Wire these as an Agent Builder flow so the multi-step chain is visible in the repo — this is the "Technological Implementation" score, and judges check that Google Cloud is *imported and actually called*, not named in a README.

Accepted SDKs: `google-adk`, `google-genai`, `google-generativeai`, or `google-cloud-aiplatform`.

Every G-call output is written to the receipt with its inputs. Model inference is always labeled `model_inference` when surfaced.

## 4. Routes

| Route | Name | Job |
|---|---|---|
| `/` | **The Board** | ON AIR light, episode window, current state. The whole product in one object. |
| `/constellation` | **The Constellation** | The flood, sorted. Tap any star for the raw signal and why it was classified. |
| `/pr/:id` | **The PR** | Three moves side by side. Sign one, or *not my look*. |
| `/drop/:id` | **The Drop** | Issued artifact, seal, edition number, claim sourcing. |
| `/verify` | **Is this real?** | Public. Paste a drop id or hash → signed / not in registry. |
| `/receipts` | **The Receipt** | Append-only log. The closing credits. |

---

## 5. Scope discipline

**Build:** the six routes, the six rules, the four Gemini calls, the fixtures, the expiry behavior.

**Do not build:** payment custody, real facial recognition, photorealistic likeness generation, freeform impersonation, real C2PA signing (simulate the manifest structure and say so), account systems, multi-star rosters, the buyer-side Star Map.

The Drop's generated content is text + a static composed card. Do not generate video.
