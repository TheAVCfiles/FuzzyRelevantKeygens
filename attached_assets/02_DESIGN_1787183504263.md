# AUTOGRAPHY — Visual Direction

The subject is a **broadcast control room at night**, seen through Technicolor. Not a dashboard, not a neon dark-mode app. The reference is physical equipment: tally lights, gel filters, rack labels, a call board, a sealed envelope.

Give this file to Replit Agent verbatim. It exists so the agent doesn't produce the default.

---

## The signature element

**Page saturation is a function of credential validity.**

When the Call is live, the interface is in full color. As `valid_until` approaches, saturation drains. When the window closes, the entire page desaturates to sepia in real time — not a modal, not a toast. The color leaves.

This is the Technicolor thesis rendered as state: *color exists only while the light is on.* It also makes expiry emotionally legible to someone who will never read a schema.

Implement as a single CSS custom property on `:root` (`--saturation: 1 → 0`) driving a `filter: saturate(var(--saturation))` on the app shell, ticked by the credential clock. Respect `prefers-reduced-motion` by stepping instead of animating.

Spend the boldness here. Everything else stays quiet.

## Color

Six values. The tally red is the only fully saturated thing on the page — never use it for anything except live credential state.

```css
--tally:   #FF2D1F;  /* ON AIR. Credential live. Nothing else. */
--house:   #120E0F;  /* Stage dark — warm near-black, never pure #000 */
--velvet:  #3A1F2B;  /* Deep plum. The rope, refusals, held states. */
--oyster:  #D9CEC4;  /* Warm pale. Primary text, paper, skin. */
--brass:   #B08D57;  /* House Seal, edition numbers, signature marks. */
--sepia:   #6B5D52;  /* The off state. Expired, dark, unresolved. */
```

Coordination clusters render in `--velvet` at varying opacity. Authentic concern renders in `--oyster`. First-party in `--brass`. Insufficient evidence renders as visible fog, not as a color — uncertainty should look like uncertainty.

Do not add a seventh color. Do not add a gradient accent.

## Type

Four roles, all Google Fonts so Replit can pull them.

| Role | Face | Use |
|---|---|---|
| Display | **Bodoni Moda** | Star name, drop titles. Playbill contrast. Used maybe four times total. |
| Body | **Archivo** | Everything readable. |
| System | **Archivo Narrow**, uppercase, tracked +0.08em | Tally labels, rule names, state. Reads like equipment lettering. |
| Data | **IBM Plex Mono** | Call IDs, hashes, edition numbers, receipts. |

The system face doing rack-label duty is what makes this feel like broadcast hardware rather than a SaaS product. Use it for every state word: `ON AIR`, `DARK`, `HUMAN HOLD`, `OUT OF SCOPE`, `SEALED`.

## Layout

The Board is not a grid of cards. It is **one object, centered, with the light above it** — the way a call board hangs on a wall.

```
┌─────────────────────────────────────────┐
│                                         │
│                ( 🔴 )                   │   tally, physical, blooming
│              ON AIR                     │   system face, tracked
│                                         │
│   ─────────────────────────────────     │
│                                         │
│   LOLA VANTZ                            │   display face
│   The Salt Flats · Episode 6            │   body
│                                         │
│   WINDOW CLOSES IN   03:41:07           │   system / mono
│   SCOPES  drop:issue  room:open  ...    │   mono, small
│                                         │
│   ─────────────────────────────────     │
│                                         │
│   [ READ THE ROOM ]                     │   one action, that's it
│                                         │
└─────────────────────────────────────────┘
```

The Constellation is the one place that goes full-bleed and dark: stars on `--house`, positioned by cluster, sized by volume. Tapping a star opens the raw signal *and* the signals that classified it. Never a chart. Never a bar.

The PR is three columns, equal weight, **Stay dark** first on the left so silence reads as a real option rather than a fallback.

## Motion

One orchestrated moment, not scattered effects.

The tally **warms up** — a filament, not a toggle. Roughly 900ms of bloom on ignition, and a slower cool-down on expiry with the saturation drain running alongside it. That is the page-load sequence and the closing sequence, and it's the only place animation earns its keep.

Everything else: instant, or a 120ms opacity fade. No scroll-triggered reveals. No parallax.

---

## Copy rules

- Active voice. The button says **Sign**; the resulting state says **Signed**.
- Refusals never apologize and are never vague. `HUMAN HOLD — no source document supports a claim about another person. Nothing was published.`
- Never write "AI" in the interface. Write what happened: *read*, *sorted*, *drafted*.
- Never write a percentage of public opinion. Write **share of observed volume**.
- Empty states are invitations: `No Call is live. Nothing can issue.`

---

## Quality floor, unannounced

Responsive to mobile. Visible keyboard focus. `prefers-reduced-motion` respected. Contrast checked — `--sepia` on `--house` fails; use `--oyster` at reduced opacity for de-emphasis instead of going darker.
